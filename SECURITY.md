# Security Policy

NORD TRACE is in early development. There is no released, deployed or
production version yet — the only supported target is the current state of the
`main` branch in this repository.

## Reporting a vulnerability

Report security issues **privately by email**:

**info@theo-picture.com**

Please do **not**:

- open a public GitHub issue for a security vulnerability;
- publish or share details of an unpatched vulnerability before a fix exists
  and a coordinated disclosure has been agreed;
- exploit an issue beyond what is reasonably necessary to confirm and report it
  safely;
- access, download or expose data, credentials or private files that a
  vulnerability would expose.

A good report includes: a description of the issue, its suspected impact, the
steps or code needed to reproduce it, the affected files or components, and —
if you have one — a suggested fix.

## What happens next

Reports are read and triaged as time permits. **No response-time commitment is
made or implied.** If you submit a report, you will be kept informed as it is
reviewed; a fix will be credited unless you prefer to remain anonymous.

Good-faith security research on this repository is described in Section 14 of
[`LICENSE.md`](LICENSE.md), which governs what is and is not permitted.

There is currently no paid bounty program and no security-audit history to
publish.
